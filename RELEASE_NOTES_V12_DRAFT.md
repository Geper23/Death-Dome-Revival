# Draft release notes — V12 (not published)

> **Experimental / First playable Android 15 test build**
>
> This file is only a **draft** for a future GitHub Release. The repository owner will publish the actual release and any authorized download assets separately.

DEATH DOME 2.1.2 is now playable on a tested Xiaomi Redmi (`tanzanite`) running Android 15, after a series of compatibility fixes.

## Highlights

- Addressed legacy Android startup problems.
- Removed a blocking dependency on obsolete game update servers.
- Fixed restricted device-identifier requests in older integrations.
- Addressed outdated preferences API usage.
- Confirmed main menu operation and completion of the first combat encounter.

## Verified

- Launch on the tested Android 15 device.
- Working main menu.
- First battle completed.

## Not yet verified

- Full progression, later encounters and inventory/shop behavior.
- Persistence of saves after app reinstall.
- Clean installation of the repackaged XAPK.
- Compatibility on other Android versions and devices.

## Installation

The intended distribution is an **XAPK** containing both the compatible APK and patched OBB. It will require an installer that supports OBB placement on the player's Android version. **The clean-install process has not yet been confirmed**, so avoid deleting a working installation.
